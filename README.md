# 🏏 Cric Info Application

An **end-to-end interactive data analysis dashboard** built using **Python** and **Streamlit** to explore, analyze, and visualize cricket statistics.

🌐 **Try the Live App Here:** [irfan-cricinfo.streamlit.app](https://irfan-cricinfo.streamlit.app/)

## 📌 Features

* **🏠 Home Dashboard:** Overview of aggregate metrics—including total players, total runs, total countries, and total matches—along with the master dataset.
* **👤 Player Analysis:** Deep-dive into individual player statistics with interactive bar charts and pie chart breakdowns (matches, innings, high scores, averages, centuries, boundaries, etc.).
* **🌐 Country Insights:** Filter by specific nations to view country-level stats like total runs, total matches, total innings, and player score comparisons.
* **⚖️ Comparison:** Perform head-to-head analysis between players or metrics.
* **📊 Data Explorer:** Interactive tabular view allowing users to scroll, sort, and inspect raw underlying data.
* **ℹ️ About Section:** Background information on the project and author links.

## 🛠️ Tech Stack

* **Language:** Python
* **Web Framework:** Streamlit
* **Data Processing & Visualization:** Pandas, Plotly
